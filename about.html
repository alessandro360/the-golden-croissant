The Project

The Golden Croissant is a fictional bakery created as an AI design experiment.

Every image, product, package, and website element was generated using AI.

The challenge was to see how far a simple idea could be developed using AI tools alone, transforming a concept into a convincing premium brand experience.

Tools Used

ChatGPT for Imagery

Claude for Web Design and Development
